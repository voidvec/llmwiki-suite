## 1. 为什么现在必须养（硬前置）

| 门槛 | 数值 | 现状评估 |
|------|------|---------|
| Show HN 最低 karma | ~5 | 新号可发，但算法压权 |
| 推荐起点 | **50-100 karma**（>2 周龄） | 需主动积累 |
| 账号龄 | **>14 天**（新号考察期） | 今天起算 09-16 才满，紧贴发布日 → **必须今天启动** |
| 历史评论 | ≥5 条领域评论 | 评论史代表账号真实活跃，非 spam |

> ⚠️ 为什么评论史重要：只有 1-2 条评论的新号发 Show HN 容易被 flag 为 spam / 自我推销。3-5 条「有上下文、有价值」的评论让账号过预审。

## 3. 去哪评论（选帖优先级）

### 3.1 主题池（按与 llmwiki 相关性排序）

| 优先级 | 主题 | 何查找 | 因为 |
|--------|------|--------|------|
| P0 | **Karpathy 的 LLM-wiki / 「Write」 / 上下文工程** | 搜 `karpathy` / `llm wiki` / Tag 页 | 我们就是这条线的工程化 |
| P0 | **本地笔记 / Obsidian / PKM 工作流** | 搜 `note-taking` / `Obsidian` / `personal knowledge` | 正是产品人群聚集地 |
| P1 | **RAG vs 检索增强 / 向量库调优** | 搜 `RAG` / `retrieval` / `BM25` | 直接命中差异化论据 |
| P1 | **Python 零依赖 / CLI 工具发布** | Show HN 里 python cli / PyPI 帖 | 建立「这号懂工程」心智 |
| P2 | **LLM 评估 / 召回指标** | 搜 `eval` / `recall` / `MRR` | 品级背书 |

> 找帖技巧: HN 首页 / https://news.ycombinator.com/newest 的「领域相关 + 30 分钟内新帖」最容易获得高质量互动；老帖（>12h）评论价值低。

### 3.2 选帖三问（发前自检）

1. 这篇帖子的作者/读者是**我的目标人群**吗？（知识库/LLM/后端开发者）
2. 我能不能给出**别人没想到的具体点**？（一个真实案例 / 一处数据 / 一个反直觉观察）
3. 这条评论发出去**不贴任何链接**也完全成立？（链接只是加分项，绝不作为主体）

## 4. 高质量评论公式（可直接套）

```
[具体观察/数据] + [一个点/对比] + [一句话开放问题或邀请]
```

示例骨架（**用真实经验填充，禁止伪内容**）：

> 「我维护的 [某个 0 依赖工具 / 某个本地库] 也遇到过类似问题——[具体细节 2-3 行]。一个反直觉的发现是：[观察]。很好奇你们在 [某个场景] 是怎么处理的？」

要点：

| 做 | 不做 |
|----|------|
| 谈问题、谈取舍、谈真实坑 | 只喊「太棒了」/ 只发链接 |
| 开门见山一两个具体点 | 长篇大论（HN 用户讨厌 essay 评论） |
| 回复他人已有评论（体现交互） | 每条都「顺便」提自己产品 |
| 每天在**不同主题**帖下（避免链评论） | 同一时间段内连续大批量刷 |

---

## 5. 红线（踩到 = 前功尽弃）

| 红线 | 后果 |
|------|------|
| **拉票**（找朋友/vote ring） | 封号 + 连带惩罚 |
| Show HN 硬广（评论里反复贴自家项目链接） | 被 flag 为促销 |
| 同 IP 多账号互顶 | 直接封全部 |
| 新号 14 天内发主题帖 | 帖不作数，且容易标记 |
| 发帖当日再发其他内容 | 稀释信誉，触发 spam |

- 评论史在发布日当天是「冻结状态」：不再新增，防止发布前意外被举报降级。
