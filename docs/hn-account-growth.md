## 2. 20 天作战时间线（按 K=1 重排：启动即冲刺）

> **顺序要点**：K=1 起步必须「先密度、再质量」——前 4 天先把评论数堆到 10+，让账号表现活跃（等级信号），
> 之后才谈高质量评论冲 karma。**评论量是启动阶段的第一优先级。**

| 阶段 | 日期 | 节奏 | 目标 |
|------|------|------|------|
| **启动冲刺期** | 09-02（今天）— 09-06 | 每日 3-5 条，覆盖 P0 主题池（Karpathy/LLM-wiki、Obsidian/PKM） | 评论数 ≥12 条，karma ≥15（活跃信号建立） |
| **积累期 A** | 09-07 — 09-13（W2） | 每日 3-4 条高质量 | karma 冲 30-40 |
| **积累期 B / 冲刺** | 09-14 — 09-16（W3 前段） | 每日 4-5 条（质量优先，多回复他人） | karma 冲 50+，评论 ≥25 条 |
| **验收检查点** | **09-17（W3 底）** | 终检 3 门槛 | karma≥50 / 龄>15 天 / 评论史达标 → 通过进 W4 |
| **降频期** | 09-18 — 09-21 | 每日 ≤2 条（避免触发过滤） | 维持活跃度，不增加风险；发布日账号冷却 |
| **发布日** | **09-22（周二 06:00-09:00 PT）** | 按 release-plan 发主帖 | 发布前账号已验证 |

> ⚠️ **K=1 的额外风险**：新号短时间大量评论（>10 条/小时）可能触发 HN 的「活跃度异常」风控。故每日 3-5 条、分散到不同时段，宁可慢一点也别触发降权。

> 若 09-17 未达标：90% 情形容忍到 09-19（发布前 3 天）再验收；仍未达标 → **W4 发布顺延 1 周**（宁缺毋滥，避免新号硬发）。

## 3. 去哪评论（选帖优先级）

### 3.1 主题池（按与 llmwiki 相关性排序）

| 优先级 | 主题 | 何查找 | 因为 |
|--------|------|--------|------|
| P0 | **Karpathy 的 LLM-wiki / 「Write」 / 上下文工程** | 搜 `karpathy` / `llm wiki` / Tag 页 | 我们就是这条线的工程化 |
| P0 | **本地笔记 / Obsidian / PKM 工作流** | 搜 `note-taking` / `Obsidian` / `personal knowledge` | 正是产品人群聚集地 |
| P1 | **RAG vs 检索增强 / 向量库调优** | 搜 `RAG` / `retrieval` / `BM25` | 直接命中差异化论据 |
| P1 | **Python 零依赖 / CLI 工具发布** | Show HN 里 python cli / PyPI 帖 | 建立「这号懂工程」心智 |
| P2 | **LLM 评估 / 召回指标** | 搜 `eval` / `recall` / `MRR` | 品级背书 |

> 找帖技巧: HN 首页 / https://news.ycombinator.com/newest 的「领域相关 + 30 分钟内新帖」最容易获得高质量互动；老帖（>12h）评论价值低。

### 3.2 选帖三问（发前自检）

1. 这篇帖子的作者/读者是**我的目标人群**吗？（知识库/LLM/后端开发者）
2. 我能不能给出**别人没想到的具体点**？（一个真实案例 / 一处数据 / 一个反直觉观察）
3. 这条评论发出去**不贴任何链接**也完全成立？（链接只是加分项，绝不作为主体）

## 4. 高质量评论公式（可直接套）

```
[具体观察/数据] + [一个点/对比] + [一句话开放问题或邀请]
```

示例骨架（**用真实经验填充，禁止伪内容**）：

> 「我维护的 [某个 0 依赖工具 / 某个本地库] 也遇到过类似问题——[具体细节 2-3 行]。一个反直觉的发现是：[观察]。很好奇你们在 [某个场景] 是怎么处理的？」

要点：

| 做 | 不做 |
|----|------|
| 谈问题、谈取舍、谈真实坑 | 只喊「太棒了」/ 只发链接 |
| 开门见山一两个具体点 | 长篇大论（HN 用户讨厌 essay 评论） |
| 回复他人已有评论（体现交互） | 每条都「顺便」提自己产品 |
| 每天在**不同主题**帖下（避免链评论） | 同一时间段内连续大批量刷 |

## 5. 红线（踩到 = 前功尽弃）

| 红线 | 后果 |
|------|------|
| **拉票**（找朋友/vote ring） | 封号 + 连带惩罚 |
| Show HN 硬广（评论里反复贴自家项目链接） | 被 flag 为促销 |
| 同 IP 多账号互顶 | 直接封全部 |
| 新号 14 天内发主题帖 | 帖不作数，且容易标记 |
| 发帖当日再发其他内容 | 稀释信誉，触发 spam |

## 6. 续接策略（当 K 增长偏慢时触发）

> **触发条件（任一）**：09-06 首周 karma <15 / 09-15 中检 <40 / 其他周复盘发现进度落后。

| 策略 | 做法 | 预计增量 | 何时用 |
|------|------|----------|--------|
| **AMA / 解疑帖** | 在 r/LLM、r/MachineLearning 类 HN 帖（而非 Show HN）下主动解答「为什么 RAG 检索常失败」等高频疑惑 | 每条高质量解答 2-5 karma | 中检前（积累期 A/B） |
| **高互动主题** | 追热点：LLM 记忆 / 上下文压缩 / 本地模型发布帖，去**跟贴**而非只赞 | 3-8 karma/条 | W3 冲刺期 |
| **「成本/实测」类评论** | LLM 工具帖下贴真实 benchmark（自己跑过的数字） | 5-10 karma（稀缺数据点） | 全期 |
| **追 Hot 帖早回** | 首页新帖 30 分钟内回评论，被看到概率最大 | 2-4 karma/条 | 全期 |

> 注意：续接策略仍是「高质量」原则，**禁止**为了 karma 发低质评论——HN 的 flag 机制对水评降权很快，得不偿失。
