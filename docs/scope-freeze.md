## 2. Non-Goals（必砍 / 降级清单，来自合同 §9.2）

为了在 9 周收口，以下**明确不做**（不因“顺手”而偷做）：

1. ❌ 健康分不做 Pro / 可视化图表库（只做单文件 HTML/JSON 基础版，对外定性“经验版 Beta”）。
2. ❌ 漏斗埋点不做全链路逐步漏斗（只上 3 事件）。
3. ❌ L1 只做 observe + suggest 两命令精简版；不做 nightly 智能汇总、L2 详细设计（留占位到 Wave 后）。
4. ❌ 不做中文物料（README 只英文；iLink 国内通道整体后置 Wave 3；Telegram 只保底）。
5. ❌ 不做多平台长跑（PH 多维选、社群运营长期战役）——只打 HN 主帖 + 对比文。
6. ❌ 不做向量/embedding 系统设计；retention 完整基线降为「可观测周报」。

> 上述冷启动若不执行，默认视为**冻结外**；任何想在冻结期插入上述任一内容的请求→必须走变更控制（§4）。

## 4. 变更控制（C0 / C1 / C2）

冻结期内任何**新增需求 / 砍功能 / 改时间线**必须走变更评审：

| 级别 | 定义 | 审批 |
|------|------|------|
| C0 | 文案/AFF 级：标题微调、素材替换、non-功能优化 | 主理人自行拍板，无需 CR 单 |
| C1 | 中幅：单个 DoD 附加验收点、非时间线调整 | 主理人批准 + 周报记录 |
| C2 | 大幅：新增/删除 D 项、改时间线、改验收指标 | 主理人签署 CR 单 + 更新实施合同（§10/§5） |

> 两条免 CR 回退：①防漂移宪法（范围冻结即冻结）；②止损 pivot 判定按合同 §5 触发，无需另行 CR。
